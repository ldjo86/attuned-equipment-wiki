# Attuned Equipment

**Des équipements qui gardent l’histoire de vos aventures.**

Attuned Equipment est un datapack pour **Minecraft Java 1.21.x**. Les armes, outils, armures et boucliers compatibles accumulent leur propre histoire. Une station d’enclume, des interactions de forge et une table d’enchantement enrichie permettent de développer leurs possibilités.

<a name="page-curseforge-fr-fonctionnalités"></a>

## Fonctionnalités

- **Histoire des équipements :** utilisations, tirs, blocages et expérience d’armure sont enregistrés sur les objets compatibles.
- **Évolutions forgées :** les paliers devenus accessibles se valident à la station d’enclume.
- **Changements de matériau :** les armes et outils compatibles peuvent poursuivre leur histoire après reforge.
- **Arcs et arbalètes personnalisés :** variantes en pierre, cuivre, fer, or, diamant et netherite.
- **Enchantements et savoirs :** des effets supplémentaires et une interface d’enchantement dédiée.
- **Reliques de structures :** dix équipements nommés, avec un récit et des enchantements vanilla.
- **Français et anglais :** le resource pack adapte les textes à la langue du client.

<a name="page-curseforge-fr-trésors"></a>

## Trésors

| Coffre de structure | Chance d’obtenir une relique supplémentaire |
| --- | ---: |
| Cité de l’End | 35 % |
| Cité antique | 25 % |
| Salle du trésor d’un bastion | 25 % |
| Pyramide du désert | 15 % |

Le tirage intervient lors de la première génération du butin. Les coffres déjà ouverts ne se remplissent pas à nouveau. Neuf reliques compatibles héritent de 100 utilisations ou points d’expérience d’armure. La hache en or conserve un rôle narratif, sans progression Attuned artificielle.

<a name="page-curseforge-fr-installation"></a>

## Installation

1. Placer le ZIP du datapack dans le dossier `datapacks` du monde.
2. Retirer les anciennes éditions Attuned de ce dossier.
3. Extraire le `resources.zip` inclus, puis l’installer et l’activer dans les packs de ressources de chaque joueur.
4. Recharger ou redémarrer le monde ou le serveur.

**Le resource pack inclus n’est pas activé automatiquement : chaque client doit l’activer.**

<a name="page-curseforge-fr-compatibilité"></a>

## Compatibilité

Cette édition cible les versions stables Java **1.21 à 1.21.11**, avec des fichiers adaptés aux changements de format. Elle ne cible pas Bedrock ou Java 26.x.

Avant 1.21.6, les actions personnalisées de forge et d’enchantement utilisent des liens cliquables dans le chat ; à partir de 1.21.6, elles utilisent les dialogues natifs. Avant l’arrivée des équipements en cuivre natifs, les épées et outils au palier cuivre utilisent une base en fer avec une identité Attuned cuivre.

Quatre tables de coffres vanilla sont remplacées afin d’ajouter les reliques. Les autres datapacks qui remplacent ces mêmes tables nécessitent une fusion.

Le wiki expose les problèmes connus de cette archive, notamment les routes de forge d’armure, le traitement des achats de tomes et l’entretien scripté de la durabilité. Les échanges de villageois préparés dans les fichiers utilisent un registre postérieur à 1.21.x ; ils ne sont pas annoncés comme fonctionnels dans cette édition. L’ancienne validation de v0.16.1 ne constitue pas une nouvelle validation en jeu de v0.17.1.
