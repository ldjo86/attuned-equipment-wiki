## Relier le projet CurseForge

Dans les paramètres du projet CurseForge, renseigner le champ **Wiki** avec :

https://github.com/ldjo86/attuned-equipment-wiki/blob/main/docs/Home.md

Le champ **Issues Tracker** peut recevoir :

https://github.com/ldjo86/attuned-equipment-wiki/issues

Le champ **Source** désigne le code du projet. Ce dépôt contient sa documentation ; si un dépôt distinct contient le code du datapack, utiliser celui-ci pour ce champ.

Les descriptions française et anglaise contiennent les adresses définitives du wiki. Elles sont prêtes à être reprises dans la présentation du projet.

## Emplacement du wiki

L’accueil publié est `docs/Home.md`. Le Wiki natif de GitHub, conservé dans un dépôt Git séparé avec le suffixe `.wiki.git`, n’a pas été alimenté par cette publication. Le lien ci-dessus donne directement accès à toute la documentation sans dépendre de cet onglet.
