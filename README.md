# Attuned Equipment — Wiki

Documentation d’**Attuned Equipment v0.17.1** pour **Minecraft Java 1.21.x**, issue de l’analyse du datapack et de son resource pack.

## [Ouvrir le wiki](docs/Home.md)

[Installation](docs/Installation.md) · [Progression](docs/Progression-et-histoire.md) · [Textures](docs/Resource-pack.md) · [English overview](docs/English-overview.md)

Attuned Equipment conserve l’histoire des armes, outils, armures et boucliers. Ce wiki explique les paliers, les matériaux, les coûts, l’enclume, la forge, les enchantements, les tomes, les recettes et les reliques, ainsi que les limites constatées dans cette version.

## Référence de cette documentation

L’analyse du **6 octobre 2026** porte sur l’archive `Attuned_Equipment_DP_1.21.x_v0.17.1.zip` et son fichier `resources.zip` inclus. Elle recense notamment **73 définitions d’enchantement**, **15 recettes**, **10 reliques** et **43 textures PNG**.

Il s’agit d’une **analyse statique** : aucun client ni serveur Minecraft n’a été lancé pour ce travail. Les problèmes déduits du code et les anciennes validations de v0.16.1 sont distingués des résultats établis pour l’archive v0.17.1.
