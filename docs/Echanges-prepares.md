# Échanges préparés

**Ces échanges ne sont pas une source de livres disponible sur Minecraft Java 1.21.x.** L’archive contient bien 36 définitions `villager_trade`, mais le registre qui permet à Minecraft de les charger a été introduit en **Java 26.1**. La présence des fichiers ne démontre pas leur fonctionnement dans les versions 1.21.x annoncées par ce datapack, ni la compatibilité générale du pack avec 26.1.

Cette page catalogue les échanges préparés pour le développement. Pour obtenir des livres en survie dans le périmètre annoncé, consultez [Reliques et butin](Reliques-et-butin.md).

Source externe : [notes officielles Minecraft Java 26.1, rubrique « Data-driven Villager Trades »](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-1). Source locale : `data/attuned/villager_trade/**/*.json` et sept tags sous `data/minecraft/tags/villager_trade/`.

## Références

Les six professions s’inscrivent dans des tags `level_5`. Le marchand ambulant utilise le tag `wandering_trader/uncommon`. Les tags ont `replace: false` ; cela exprime une intention d’ajouter des offres, sans remplacer toute la sélection. Chaque définition précise aussi `reputation_discount: 0.1`.

Les modificateurs de livres renseignent les enchantements stockés ou le type de tome. Le catalogue [echanges-prepares.csv](../catalogues/echanges-prepares.csv) conserve les 36 prix exacts et leur statut ; [echanges-prepares.json](../catalogues/echanges-prepares.json) contient toutes les données source. Aucune fonction d’injection directe des offres dans les villageois 1.21.x n’a été identifiée dans cette archive.
